Privacy Policy

Last updated: November 19, 2026

workspace-mcp-app is a personal tool used only by its owner to access the owner's own Google accounts.

Data accessed

With the owner's consent, the app accesses Google user data (Gmail, Calendar, Drive, Docs, Sheets, Tasks, Contacts) through Google APIs, only to perform actions the owner requests.

Storage

OAuth tokens are stored locally on the owner's computer. Google user data is not stored on any server operated by this app, is not sold, and is not shared with third parties except as needed to process the owner's own requests.

Limited Use

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Contact

Questions: open an issue at github.com/asalamatov/workspace-mcp/issues.
